# قیمت‌یاب شماره رند

Next.js (App Router) + HeroUI v3 + Prisma/PostgreSQL. شماره موبایل را وارد می‌کنید و قیمت تقریبی را مثل یک قیمت‌گذار واقعی پیدا می‌کند: رقم‌هایی که شماره را رند می‌کنند نگه می‌دارد، بقیه را خالی می‌گذارد (مثلاً برای 09121003088 جستجوی `0912-00-0`) و قیمت آگهی‌های همان الگو را می‌خواند.

## ۱. اجرا روی سیستم خودتان
نیاز: Node 22 و Docker (یا یک PostgreSQL دلخواه).
```bash
docker compose up -d            # PostgreSQL روی پورت 5432 (کاربر/رمز/دیتابیس: rond)
cp .env.example .env            # سپس مقادیر را تنظیم کنید (پایین را ببینید)
npm install
npx prisma migrate deploy
npm run seed                    # کاربر ادمین + ۴۰ آگهی نمونه
npm run dev                     # http://localhost:3000
```
مقادیر نمونه برای `.env` با docker-compose بالا:
```
DATABASE_URL="postgresql://rond:rond@localhost:5432/rond"
AUTH_SECRET="هر رشتهٔ تصادفی حداقل ۱۶ کاراکتر"
ADMIN_USERNAME="admin"
ADMIN_PASSWORD="یک رمز دلخواه"
```

## جستجوی زنده در rond.ir (مشابه‌ترین شماره‌ها)
صفحهٔ اصلی برای هر شماره همان لحظه در rond.ir جستجو می‌کند (`lib/rond/similar.ts`):
1. نوع رند خود شماره را از rond.ir می‌گیرد (`rond-bot`، مثلاً 09121003088 = «کد پایین + هزاری از اول»).
2. با فیلتر همان نوع‌ها و خانه‌های ۷تایی سایت (`simCardNumberWithoutPreCodePattern`، هر خانه یک رقم یا `\d`) جستجو می‌کند: خود شماره، هر ۷ حالتِ یک رقم عوض‌شده، بعد خالی کردن خانه‌ها از آخر (رقم‌های اول که «کد» را می‌سازند می‌مانند) تا ۸ آگهی قیمت‌دار پیدا شود. نسخه‌های جابه‌جاشده (1234567 → 2345678 …) هم جستجو می‌شوند.
3. رتبه‌بندی: چقدر از ساختار رند (رقم‌های تکراری، دنباله‌ها) شکسته شده + یکی بودن نوع رند (برای ۱۵ آگهی اول از rond.ir پرسیده می‌شود)، بعد تعداد خانه‌های یکسان.
4. قیمت میانهٔ آگهی‌هایی است که تقریباً به اندازهٔ نزدیک‌ترین آگهی شبیه‌اند. اگر خود شماره آگهی داشته باشد، همان قیمت.

هر جستجو حدود ۳۰ تا ۵۰ درخواست و ۴ تا ۱۰ ثانیه است.

rond.ir پشت ArvanCloud است و بدون کوکی مرورگر صفحهٔ «در حال انتقال» برمی‌گرداند. پس:
1. rond.ir را در مرورگر خودتان باز کنید، DevTools ← Application ← Cookies ← `https://rond.ir`.
2. مقدار `__arcsjs` و `__arcsjsc` را در `.env` بگذارید: `ROND_COOKIE="__arcsjs=...; __arcsjsc=..."`
3. سرور را دوباره اجرا کنید. کوکی حدود ۲۴ ساعت معتبر است؛ وقتی منقضی شود، جستجو به دیتابیس محلی برمی‌گردد و در لاگ سرور پیام `set ROND_COOKIE` می‌آید.

## ۲. جمع‌آوری داده از rond.ir و یادگیری فرمول
این مرحله روی سیستم خودتان اجرا می‌شود (باید rond.ir در دسترس باشد):
```bash
npm run rond:discover   # کد سایت rond.ir را می‌خواند و فیلد فیلتر «نوع رند» را پیدا و تست می‌کند -> data/rond-api.json
npm run rond:collect    # همهٔ آگهی‌های پیش‌شماره‌های همراه اول + برچسب ۴۲ نوع رند (قابل ادامه بعد از قطع شدن)
npm run rond:learn      # دقت تشخیص الگوها، ضریب پیش‌شماره و وضعیت سیم، و بک‌تست خطا -> data/model.json
```
- فقط یک پیش‌شماره: `npm run rond:collect -- --precodes=0912`
- سرعت: `--delay=400` (میلی‌ثانیه بین درخواست‌ها)، `--size=100`، شروع از اول: `--fresh`
- اگر سایت کوکی خواست: `ROND_COOKIE="..." npm run rond:collect` (کوکی را در فایل‌ها ذخیره نکنید)
- اگر `rond:discover` فیلد نوع رند را پیدا نکرد: فایل `data/rond-api.json` را بفرستید، یا دستی `ROND_ALGO_FIELD=<نام فیلد>` بدهید.
- بعد از `rond:learn` فایل `data/learn-report.json` را بفرستید تا تشخیص الگوهایی که با rond.ir نمی‌خوانند اصلاح شود.

## ۳. به‌روزرسانی خودکار هر ساعت
`npm run rond:sync` هر ساعت کل آگهی‌های rond.ir را دوباره می‌گیرد:
- آگهی‌های جدید و تغییر قیمت‌ها ذخیره می‌شوند.
- آگهی‌هایی که دیگر در rond.ir نیستند (فروخته یا حذف شده) غیرفعال می‌شوند و در قیمت‌گذاری و جستجو حساب نمی‌شوند.
- برچسب‌های «نوع رند» روزی یک بار تازه می‌شوند و بعد مدل قیمت (`data/model.json`) دوباره یاد گرفته می‌شود.
- هم‌زمان فقط یک worker اجرا می‌شود؛ اجرای دوم خودش خارج می‌شود. تاریخچهٔ اجراها در `/panel/admin` دیده می‌شود.

روش اجرا (یکی را انتخاب کنید):
```bash
npm run rond:sync                              # در یک ترمینال باز بماند
npx pm2 start npm --name rond-sync -- run rond:sync   # پس‌زمینه، با pm2
docker compose --profile worker up -d          # سرویس Docker کنار دیتابیس
```
یا با cron (هر ساعت یک بار، دقیقهٔ ۷):
```
7 * * * * cd /path/to/khatmarket && npm run rond:sync -- --once >> sync.log 2>&1
```
تنظیمات اختیاری در `.env`: `ROND_SYNC_INTERVAL_MIN=60`، `ROND_SYNC_LABELS_HOURS=24`، `ROND_SYNC_PRECODES=0912,0919`، `ROND_SYNC_DELAY=400`.

اگر یک دور کامل بیشتر از یک ساعت طول بکشد (همهٔ پیش‌شماره‌ها چند صد هزار آگهی است)، دور بعدی بلافاصله بعد از آن شروع می‌شود و هیچ‌وقت دو دور هم‌زمان اجرا نمی‌شوند. برای دورهای سریع‌تر `ROND_SYNC_PRECODES` را محدود کنید.

## صفحه‌ها
- `/` برآورد قیمت: الگوها، «جستجوی معادل» (مثل `0912-00-0`)، بازهٔ قیمت و آگهی‌های همان الگو.
- `/search` جستجوی خانه‌ای مثل فیلتر شمارهٔ rond.ir (خانهٔ خالی = هر رقمی).
- `/panel` تاریخچهٔ استعلام‌ها، `/panel/admin` آمار و وارد کردن دستی JSON.
- ثبت‌نام آزاد با نام کاربری/رمز عبور (بدون OTP)، نقش‌ها: `ADMIN` / `USER`.

## کد
- `lib/numbers/mask.ts` ساخت جستجوهای خانه‌ای از رقم‌های رند
- `lib/numbers/estimate.ts` قیمت از دقیق‌ترین جستجویی که آگهی کافی دارد (میانهٔ پیراسته، ضریب پیش‌شماره و وضعیت)
- `lib/numbers/patterns.ts` و `lib/numbers/algorithms.ts` الگوهای rond.ir با شناسه‌های واقعی‌شان
- `scripts/rond-*.ts` جمع‌آوری و یادگیری
